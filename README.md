
# Escape School

**An educational escape-room game developed as part of an engineering thesis project.**

## About the Project

Escape School is an educational game that combines escape-room mechanics with mathematical challenges. Players progress through the game by solving problems and completing tasks based on the secondary school mathematics curriculum.

The project was developed as part of an engineering thesis, with the goal of combining interactive gameplay with educational content.

## Features

- Educational escape-room gameplay
- Mathematical exercises based on the secondary school curriculum
- Interactive puzzles and challenges
- Progression through problem-solving
- Game environment designed around educational activities

## Technologies

- **Game Engine:** Godot Engine 4.5
- **Programming Language:** GDScript

## Requirements

To open and run the project, you need:

- Godot Engine 4.5 or a compatible version

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Nostalgiox/escape-school.git
```

### 2. Open the project

1. Launch Godot Engine.
2. Select **Import**.
3. Navigate to the cloned repository.
4. Select the `project.godot` file.
5. Open the project.

### 3. Run the game

Once the project has been imported, press **F6** to run the current scene or **F5** to run the main project scene.

## Project Structure

The repository contains the Godot project source files, including scenes, scripts, resources and project configuration.

## Important Note

This repository contains the Godot project files and source code. It does not include an exported standalone executable.

To run the game, open the project using Godot Engine.
